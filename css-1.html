CSS 1 — Styling Basics

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, spacing, and layout. HTML is the structure; CSS is the design.

1. How to Add CSS

Three common ways:

  • Inline — style attribute on one element
  • Internal — style tag inside the head
  • External — separate .css file linked with link (best for bigger projects)
link rel="stylesheet" href="style.css"
Code Lab uses an external stylesheet (style.css) so all pages share the same theme.

2. Selectors & Properties

A CSS rule looks like this:

selector { property: value; }

Example — make all paragraphs muted gray:

p { color: black; font-size: 16px; }

3. Common Properties (Beginner)

  • color — text color
  • background-color — background of an element
  • font-size / font-weight — size and boldness
  • padding — space inside an element
  • margin — space outside an element
  • border / border-radius — outlines and rounded corners
This box uses padding, border-radius, and a gradient background.

4. Classes & IDs

Use classes to style groups of elements. Use IDs for unique elements.

div class="card".../div .card { background: #1a1d24; padding: 28px; border-radius: 14px; }
Prefer classes over IDs for most styling. Classes can be reused; IDs should be unique on the page.
