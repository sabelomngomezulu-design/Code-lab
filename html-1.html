HTML 1 — The Basics

HTML is the skeleton of every webpage. It gives structure: headings, paragraphs, lists, links, and images.

1. What is HTML?

HTML stands for HyperText Markup Language. It uses tags to mark up content so browsers know what each part is.

Most tags come in pairs: an opening tag and a closing tag.

This is a paragraph./p

2. Basic Page Structure

Every HTML page follows a simple skeleton:

!DOCTYPE html My Page
The head holds information about the page. The holds everything the user sees.

5. Links & Images

Links use the a tag. Images use <img> (self-closing).

a href="page.html"Click me/a img src="photo.jpg" alt="Description";
Always add an alt attribute to images. It helps accessibility and shows text if the image fails to load.
