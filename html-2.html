Let’s Dive Deeper into HTML Elements

Important building blocks you will use on almost every page: containers, classes, buttons, links, and navigation.

div

A div is a container element that can hold other HTML elements. It is often used to group related content together and apply CSS styles or JavaScript functionality to that group of elements.

class

Classes are used to define CSS styles for HTML elements. Classes can be applied to multiple elements, allowing you to reuse the same styles across different parts of your website.

button

Buttons are interactive elements that allow users to perform actions on a website. They can be used to submit forms, trigger JavaScript functions, or navigate to other pages.

a (anchor / link)

The a element is used to create hyperlinks, which allow users to navigate to other web pages or resources. The href attribute specifies the URL of the page or resource that the link points to.

link

The link element is used to link to external resources, such as CSS files or favicons. The href attribute specifies the URL of the resource that the link points to. It lives in the head of the document.

Styling in HTML

Styling is done using CSS (Cascading Style Sheets). CSS allows you to control the layout, colors, fonts, and other visual aspects of your web pages. You can apply styles with inline styles, internal stylesheets, or external stylesheets.

nav

The nav element is used to define a set of navigation links. It is commonly placed at the top or side of a website to help users jump between different pages or sections.
