CSS 2 — Layout & Theme

Go further with Flexbox, CSS variables, hover effects, and clean layout techniques used across Code Lab.

1. CSS Variables (Custom Properties)

Define colors and values once, then reuse them everywhere. This keeps the theme consistent.

:root { --bg: #0f1115; --surface: #1a1d24; --accent: #f9c74f; --text: #e8eaed; } body { background: var(--bg); color: var(--text); }

2. Flexbox Basics

Flexbox makes it easy to align items in a row or column and distribute space.

.nav { display: flex; justify-content: space-between; align-items: center; gap: 16px; }

The navigation bar and card layouts on this site use Flexbox.

3. Hover & Transitions

Make interfaces feel alive with simple transitions.

.btn { transition: 0.2s ease; } .btn:hover { transform: translateY(-2px); opacity: 0.9; }

4. Box Model Reminder

Every element is a box with content, padding, border, and margin.

  • content — text or children
  • padding — space inside the border
  • border — the edge around the padding
  • margin — space outside the border
* { box-sizing: border-box; }
Using border-box makes width and height include padding and border, which is easier for beginners.

5. Putting It Together

You now know enough to style a full page:

  • Use CSS variables for a consistent theme
  • Style with classes (not only element selectors)
  • Use Flexbox for navigation and card rows
  • Add small hover effects and smooth transitions
  • Keep spacing consistent (padding and margin)
